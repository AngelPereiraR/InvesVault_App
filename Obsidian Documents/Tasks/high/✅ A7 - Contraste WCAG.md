# ✅ A7 — Contraste WCAG

**Origen**: #UI-5
**Prioridad**: Alta | **Estado**: ✅ Completada | **Esfuerzo**: Bajo

## Problema

`textHint` (2.9:1), `success` (1.8:1) y `primary` (3.6:1) no cumplen WCAG AA.

## Tarea

- `textHint` → #757575 (4.6:1)
- `success` → #2D6A4F para texto, mantener #74C69D para fondos
- Usar `primaryDark` (#2D6A4F) para texto verde
- Actualizar referencias en shopping list, stat buttons, etc.
- Verificar tema oscuro.

## Impacto

App legible para usuarios con visión reducida. Esfuerzo bajo.
